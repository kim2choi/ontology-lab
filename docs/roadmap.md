# Roadmap

## Phase 1 — Foundations (0–2 months)
- Formal ontology
- Knowledge representation
- First-order logic backfill
- Description logics
- RDF / RDFS / OWL
- Ontology design and evaluation
- Ontology alignment
- Ontology learning
- LLM + ontology

## Phase 2 — Ontology Engineering (2–4 months)
- Competency questions
- Reusable modelling patterns
- Protégé workflows
- Reasoning and consistency checks
- Documentation and modelling decisions

## Phase 3 — Production Knowledge Graphs (4–6 months)
- RDFLib / ETL
- SHACL validation
- SPARQL
- Triple stores
- APIs and pipelines
- Testing and CI

## Phase 4 — Integration & Architecture (6–9 months)
- Ontology matching and mappings
- Canonical models
- Governance and versioning
- Migration and backward compatibility

## Phase 5 — Research Engineering (9–12 months)
- Ontology learning
- LLM-assisted ontology engineering
- KG + RAG
- Neuro-symbolic systems
- Experimental evaluation

## Phase 6 — Technical Leadership (12+ months)
- Modelling reviews
- Governance
- Architecture decisions
- Stakeholder communication
- Team standards and review processes
