# Ontology Lab

Engineering and research workspace for ontology, knowledge representation, knowledge graphs, and LLM-assisted ontology engineering.

## Current Phase
Phase 1 — Foundations

## Current Topics
- Formal Ontology
- Knowledge Representation
- Description Logics
- RDF / RDFS / OWL

## Project Track
### P01 — AI Research Ontology
Status: Planning

Goal: model researchers, papers, datasets, models, tasks, benchmarks, institutions, and research topics, then validate the ontology with competency questions, reasoning, SHACL, and SPARQL.

## Workflow
Paper → Closed-book reconstruction → Modeling → Implementation → Validation → Review

- `shacl/` — SHACL shapes

- `experiments/` — research experiments
